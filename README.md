# GaraBlox

Красивый лаунчер-оболочка для Roblox: своё главное меню, избранные игры в один клик,
профили аккаунтов, темы оформления и установка официального клиента прямо из лаунчера.

**Чем это не является:** это не самописный клиент Roblox и не замена движка. Игры открываются
официальным клиентом Roblox (или Fishstrap / Bloxstrap, если так выбрано) по ссылке
`roblox://experiences/start?placeId=…`. Файлы Roblox не патчатся, авторизация не подменяется.

---

## Возможности

- **Своё меню.** Тёмный интерфейс, герой-блок с любимой игрой, сетка избранного, боковая навигация.
- **Запуск игры в один клик** — через системный обработчик `roblox://`, Fishstrap, Bloxstrap или свой `.exe`.
- **Установка Roblox** из официального установщика (`roblox.com/download/client`) в тихом режиме, с прогрессом.
- **Профили аккаунтов** — именованные пометки, чтобы не путаться. Без паролей, cookies и автологина.
- **Скины лаунчера** — 5 тем, 6 акцентов, три варианта фона, режим «меньше анимаций».
- **Избранное** — добавление по ссылке или ID игры, подтягивание названия, автора и статистики
  через официальные публичные API Roblox.

## Запуск

Нужен установленный [Node.js](https://nodejs.org) 18 или новее.

```bash
cd garablox
npm install
npm start
```

Или просто двойной клик по `start.cmd` — он сам поставит зависимости при первом запуске.

## Как это работает

| Что | Как |
|---|---|
| Запуск игры | `roblox://experiences/start?placeId=…`; для Fishstrap/Bloxstrap — `Fishstrap.exe -player "<uri>"` |
| «Авто» | ссылку обрабатывает тот клиент, что зарегистрирован в Windows как обработчик `roblox://` |
| Установка | скачивается официальный установщик и запускается с `/silent` |
| Аккаунты | только локальные пометки; переключение — вручную в клиенте Roblox |
| Скины | CSS-темы интерфейса лаунчера, к Roblox отношения не имеют |
| Обложки | `thumbnails.roblox.com`; если CDN недоступен, рисуется аккуратный фолбэк |

Настройки хранятся в `%APPDATA%\garablox\garablox-state.json` (кнопка «Открыть» в настройках).

## Сборка в .exe (по желанию)

```bash
npx electron-builder --win portable
```

Первый запуск подтянет electron-builder и соберёт портативный файл в `dist/`.

## Структура

```
main.js            главный процесс: IPC, поиск клиентов, установка, запуск
preload.js         безопасный мост window.garablox
src/index.html     каркас интерфейса
src/styles.css     темы и вёрстка
src/renderer.js    вся логика интерфейса (+ демо-режим при открытии в браузере)
tools/make-icon.ps1 генератор иконки
```

## Важно

Неофициальные лаунчеры могут нарушать правила Roblox. Проект ничего не обходит: не патчит клиент,
не вмешивается в античит и авторизацию, не помогает с банами и мультиаккаунт-обходом.
Используй на свой риск.
